ArrayList:
    ArrayList is a resizable array implementation in Java that is part of the java.util package.
    Unlike arrays, ArrayList can dynamically grow in size as elements are added or removed.
    
    Key characteristics of ArrayList:
    1) Dynamic Size: ArrayList grows automatically when elements are added beyond its current capacity.
    2) Non-Synchronized: Unlike Vector, ArrayList is not synchronized, making it faster in single-threaded environments.
    3) Default Capacity: Initial capacity is 10 elements. When capacity is exceeded, it expands by 50% of current size.
    4) Index-Based: Elements are accessed by index (0-based), providing O(1) access time.
    5) Generics Support: ArrayList supports generics for type safety (e.g., ArrayList<String>).
    
    Syntax to create ArrayList:
    ArrayList<String> list = new ArrayList<>(); // Generic ArrayList
    ArrayList list = new ArrayList(); // Non-generic ArrayList
    
    Common ArrayList Methods:
    1) add(E element) - Adds element to the end
    2) add(int index, E element) - Inserts element at specified index
    3) get(int index) - Retrieves element at index
    4) remove(int index) - Removes element at index
    5) size() - Returns number of elements
    6) clear() - Removes all elements
    7) contains(Object o) - Checks if element exists
    
    Time Complexity:
    - Access: O(1)
    - Insertion: O(n) - requires shifting elements
    - Deletion: O(n) - requires shifting elements
    - Search: O(n)
    
    When to use ArrayList:
    - When you need frequent access to elements by index
    - When working in single-threaded environments
    - When you need dynamic sizing without synchronization overhead
    - Most commonly used collection in Java applications
