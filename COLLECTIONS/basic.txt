Stack:
    Stack is a linear data structure that follows the LIFO principle (Last In, First Out).
    In Java, Stack is a class in the java.util package that extends the Vector class.
    Because it extends Vector, Stack is synchronized and supports indexed access, but it is mainly used for LIFO behavior.

    Special methods provided by Stack:
                       1) push
                       2) pop
                       3) peek
                       4) search
                       5) empty

    Important points about Stack:
    * Stack was introduced in Java 1.0.
    * default capacity: 10
    * initial capacity: 10
    * It allows duplicate elements and null values.
    * It maintains insertion order through push/pop operations.
    * peek() returns the top element without removing it.
    * pop() removes and returns the top element.
    * It is synchronized.
    * It is commonly used in undo/redo operations, recursion, expression evaluation, and backtracking.
